# 📱 Flutter Railway App

## 🚀 Overview

This is a Flutter-based mobile application developed as part of a MCA semester 2 project.
It simulates a railway booking system with user-friendly features.

## 🛠️ Tech Stack

* Flutter (Dart)
* Android SDK
* Firebase (if used)

## ✨ Features

* User login/signup
* Train search
* Booking interface
* Profile screen

## 📦 APK

APK file is available in the Releases section.

## ⚙️ How to Run

```bash
git clone https://github.com/aishwaryasingh2410-dot/Flutter-Railway-App
cd Flutter-Railway-App
flutter pub get
flutter run
```
